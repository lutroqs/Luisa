# Projetos da Luisa

Site estático com os meus projetos. Não precisa de build: o Vercel publica os arquivos como estão.

| Pasta | Projeto |
|---|---|
| `luisa-troquetti/` | Portfólio |
| `escritorio-da-luisa/` | Escritório virtual (instalável no celular) |
| `nexlu-luisa-os/` | LUISA OS — central de estudos (prévia) |
| `laboratorio-sql/` | Laboratório SQL com 27 exercícios |

A página inicial (`index.html`) liga para todos.

## Publicar no Vercel
1. Em vercel.com → **Add New → Project** → importe este repositório do GitHub.
2. Framework Preset: **Other**. Deixe Build Command e Output Directory vazios.
3. **Deploy**. Cada novo commit no GitHub atualiza o site sozinho.
